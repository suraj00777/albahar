# Hotel Al-Bahar, Belagavi

3D restaurant website with online ordering, order tracking and an admin panel (`#admin`).

## Go live with real orders (Supabase)
1. Create a free project at supabase.com.
2. SQL Editor → paste `supabase.sql` → Run.
3. Authentication → Users → Add user (owner email + password) — this is the admin login.
4. Project Settings → API → copy Project URL and anon public key into `config.js`.
5. Commit; GitHub Pages updates in about a minute.

Until then the site runs in demo mode (orders stay in the browser, admin PIN 1234).
